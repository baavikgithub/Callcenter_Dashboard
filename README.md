# 📊 Call Center Performance Dashboard (Power BI)

## 🔍 Overview

This project focuses on analyzing call center operations using Power BI to track key performance metrics and improve customer service efficiency.
The dashboard provides insights into call volume, agent performance, customer satisfaction, and operational KPIs.

---

## 🎯 Objectives

* Monitor overall call center performance
* Identify inefficiencies in call handling
* Improve customer satisfaction and reduce abandonment rate
* Enable data-driven decision making

---

## 📌 Key Metrics (KPIs)

* 📞 Total Calls
* ✅ Calls Handled
* ❌ Abandon Rate
* ⏱️ Average Speed of Answer (ASA)
* ⌛ Average Handling Time (AHT)
* ⭐ Customer Satisfaction (CSAT)
* 📊 Net Promoter Score (NPS)

---

## ⚙️ Tools & Technologies

* Power BI (Data Visualization)
* DAX (Measures & KPIs)
* Power Query (Data Cleaning & Transformation)
* Excel / CSV Dataset

---

## 📈 Key Features

* Interactive dashboard with slicers and filters
* Department-wise performance analysis
* Monthly trend analysis for calls and abandonment rate
* KPI cards for real-time performance tracking
* Drill-down capabilities for deeper insights

---

## 🧠 Insights

* Identified departments with high abandon rates impacting customer experience
* Highlighted top-performing departments based on CSAT and NPS
* Observed trends in call volume fluctuations over time
* Found correlation between AHT and customer satisfaction
